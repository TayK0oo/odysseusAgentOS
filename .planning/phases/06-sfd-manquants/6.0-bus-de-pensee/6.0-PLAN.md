# Phase 6.0 — Bus de pensée : Plan

**Date :** 2026-07-22 | **Contexte :** [5.1.5-CONTEXT.md](../../05-activation/5.1.5-design-conception/5.1.5-CONTEXT.md)

## Objectif

Implémenter le Bus de pensée event-driven — le système nerveux d'Agent OS qui orchestre le cheminement en 7 phases et permet aux modules de s'abonner via `@on_phase`.

## Tâches

### T1 — Module `src/thought_bus/` (core)
- [x] `events.py` — PhaseEvent enum, BusContext dataclass
- [x] `subscriber.py` — @on_phase decorator, PhaseSubscriber, SubscriberRegistry
- [x] `bus.py` — ThoughtBus: phase walker + event emitter
- [x] `__init__.py` — Public API exports
- [x] `integration.py` — ThoughtBusBridge for agent_loop integration

### T2 — Kill-switch
- [x] `ODYSSEUS_THOUGHT_BUS` dans `killswitch_registry.py` (ON par défaut, cœur stable)

### T3 — Tests
- [ ] `tests/test_thought_bus.py` — Unit tests

### T4 — Documentation
- [ ] Mise à jour `docs/architecture/design-document.md` si nécessaire

## Critères de succès
- [ ] Le ThoughtBus peut marcher les 7 phases sans subscriber
- [ ] Un subscriber décoré avec `@on_phase("BUILD")` reçoit les événements ENTER/EXIT
- [ ] Un subscriber avec `enabled=False` est ignoré
- [ ] Le kill-switch `ODYSSEUS_THOUGHT_BUS=off` désactive le bus
- [ ] L'intégration avec stream_agent_loop fonctionne via ThoughtBusBridge
- [ ] Tests passent
