# Phase 5.3 — Activer Mem0 + Meilisearch

**Milestone :** M5 — Activation | **Phase :** 5.3 | **Autonomous :** false
**Dépendances :** 5.2 (phase-lock)
**Effort :** 2h

---

## Objectif

Activer Mem0 (mémoire intelligente avec extraction de faits) et Meilisearch (full-text search).

## Kill-switches à activer

```bash
ODYSSEUS_MEM0=on        # Déjà actif ?
ODYSSEUS_MEILISEARCH=on
```

## Services Docker à démarrer

```bash
docker compose up -d meilisearch
```

## Fichiers de référence

| Fichier | Contenu |
|---------|---------|
| `services/memory/mem0_provider.py:399` | Provider Mem0 — extraction auto de faits |
| `services/search/meilisearch_client.py:281` | Client Meilisearch — full-text search |
| `routes/memory_routes.py:50` | Endpoint `/api/memory/facts` |
| `routes/search_routes.py:38` | Endpoint `/api/search/fulltext` |
| `docker-compose.yml` | Service meilisearch (port 7700) |

## Actions

1. Démarrer Meilisearch : `docker compose up -d meilisearch`
2. Vérifier Mem0 : `curl /api/memory/facts` retourne des faits extraits
3. Vérifier Meilisearch : `curl /api/search/fulltext?q=test` retourne résultats
4. Indexer les messages existants dans Meilisearch
5. Tester la recherche typo-tolerant ("restaurent" → "restaurant")

## Validation

- [ ] Mem0 extrait automatiquement les faits des conversations
- [ ] Meilisearch répond en < 50ms
- [ ] Recherche typo-tolerant fonctionnelle
- [ ] UI search-chat.js utilise le nouvel endpoint
