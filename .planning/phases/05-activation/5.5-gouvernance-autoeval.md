## Objectif

Activer la gouvernance (ancestry) et l'auto-évaluation (keep/revert).

## Kill-switches à activer

```bash
ODYSSEUS_GOVERNANCE_ANCESTRY=on
ODYSSEUS_AUTOEVAL=on
ODYSSEUS_CHECKPOINT=on
ODYSSEUS_UNIFIED_TOKENS=on
ODYSSEUS_CODEBURN=on
```

## Actions

1. Ajouter les 5 kill-switches dans `.env`
2. Redémarrer l'app
3. Lancer un chat avec un projet → vérifier ancestry dans les logs
4. Vérifier : `curl /api/governance/budgets` retourne les budgets
5. Vérifier : `curl /api/autoeval/health` retourne le statut
6. Vérifier : `curl /api/observer/drift` montre des runs trackés
