# Phase 5.1 — Installer dépendances

**Milestone :** M5 — Activation | **Phase :** 5.1 | **Autonomous :** false
**Dépendances :** M4 (documentation)
**Effort :** 30min

---

## Objectif

Installer toutes les dépendances Python et Node.js pour activer les 22 outils intégrés.

## Fichiers de référence

| Fichier | Contenu |
|---------|---------|
| `requirements.txt` | 57+ dépendances Python (déjà à jour avec global-v1) |
| `requirements-optional.txt` | Dépendances optionnelles (Docling, DeepEval, Ragas…) |
| `package.json` | Tailwind CSS, Promptfoo, PurgeCSS |
| `docker-compose.yml` | 21 services Docker |

## Actions

1. `pip install -r requirements.txt`
2. `npm install`
3. `npm run css:build`
4. Vérifier : `python -c "import app; print('OK')"`
5. Vérifier : CSS < 200 KB
